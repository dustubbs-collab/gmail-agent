gmail-agent (personal)
A private Gmail reader for my home AI agent. It runs on my own server and
reads my own Gmail account with read-only access. It is not a product and
is not offered to anyone else.
What it does
Reads messages and attachments from my Gmail account.
Lets my personal AI assistant search and summarize my mail.
No data is sent to any third party beyond Google's Gmail API and the
  AI models I choose.
Privacy
This app accesses only my own Gmail account, using Google OAuth with the
read-only scope (gmail.readonly). It does not read anyone else's mail,
does not share mail contents with third parties, and does not store mail
outside my own server. Credentials stay on my own machines.
